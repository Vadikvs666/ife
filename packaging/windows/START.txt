IFE — Windows

Распакуйте весь архив в отдельную папку и запустите IFE.exe.
Файлы ife.jar и папка lib должны оставаться рядом с IFE.exe.

Требуется установленная Java 8 с JavaFX и .NET Framework 4.x.
Java в архив не включена. На компьютере, где собрана эта версия,
подходящая Java уже установлена.

В приложении укажите параметры почты и MySQL через «Настройки».
Файлы внутри ZIP отображаются в списке вложений после выбора письма.
XLS отправляются на сервер конвертации, указанный в настройках.
XLSX обрабатываются на компьютере. Имена в ZIP показаны как архив.zip/файл.xls.

Журналы запуска: %LOCALAPPDATA%\IFE\logs

Если IFE.exe не запускается, можно запустить ife.jar через Java 8:
java -jar ife.jar
