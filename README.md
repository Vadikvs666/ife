# IFE

Java 8 / JavaFX: импорт счетов из почтовых вложений и файлов Excel.

## Запуск одного JAR на Windows и Linux

`ife-012.jar` содержит приложение и его библиотеки; папка `lib` не нужна.
Требуется Java 8 с JavaFX для вашей операционной системы и графическое окружение.
Запуск: `java -jar ife-012.jar`.
Настройки почты, MySQL, сервера конвертации и пути к браузеру задаются на каждом компьютере.

Сборка этого JAR в подготовленном окружении Windows:
`powershell -ExecutionPolicy Bypass -File packaging/jar/build.ps1`.
Скрипт использует Java 8 с JavaFX, компилятор `ecj.jar` и библиотеки из каталога,
указанного через `-DependencyDirectory` (по умолчанию `%TEMP%\ife-java-check`).

## Вложения ZIP

Выберите письмо и дождитесь чтения вложений. Список показывает сам ZIP и файлы
внутри него, например `счета.zip/поставщик/счёт.xls`. Выберите нужный файл,
нажмите `-->`, затем используйте «Сохранить» или обычную отправку после выбора фирмы.

- Поддерживаются папки внутри ZIP и русские имена в UTF-8 и CP866.
- При сохранении используется имя файла без папок архива. Существующий файл
  с тем же именем не перезаписывается: выберите другую папку.
- Повреждённые архивы показывают предупреждение; другие вложения остаются доступны.
- ZIP с паролем и раскрытие ZIP внутри другого ZIP не поддерживаются.
- Ограничения: 100 МБ на архив/извлекаемый файл, 10 000 записей в одном ZIP.

## Excel

XLSX читаются локально Apache POI. XLS и другие форматы, как в исходной версии,
отправляются на сервер из настройки «Сервер конвертирования файлов».
Это относится и к файлам, выбранным внутри ZIP. Используется прежний адрес по
умолчанию: http://convert.hoz.center/converttoxlxs; ранее сохранённый адрес сохраняется.
Для конвертации требуется доступный сервер. При его ошибке импорт останавливается.
Для формул используется результат, сохранённый в книге Excel; пересчёт не выполняется.
Строки с некорректным количеством или суммой пропускаются с записью в журнал;
чтение остальных строк и передача успешно прочитанных товаров продолжаются.

## Проверки

Требуются JDK 8 с JavaFX и Maven. Запуск тестов: `mvn test`.
Тесты создают MIME-письма, ZIP и Excel локально и не подключаются к почте или MySQL.
